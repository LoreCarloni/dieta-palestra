# Tabelle di composizione degli alimenti CREA

- Fonte: Tabelle di composizione degli alimenti, aggiornamento 2019, CREA Alimenti e Nutrizione, consultabili su https://www.alimentinutrizione.it/tabelle-nutrizionali
- Scaricate il 25 ottobre 2026 (832 schede alimento).

## File

- alimenti_nutrienti.csv: una riga per nutriente e alimento. Colonne: codice, alimento, categoria, nutriente, unita, valore_100g, min, max, valore_porzione, origine_dato, metodiche, referenze. I valori "tr" indicano traccia.
- codici_alimenti.txt: codici delle 832 schede scaricate.

Le schede HTML originali non sono nel repository per dimensione. Si possono riscaricare da https://www.alimentinutrizione.it/tabelle-nutrizionali/<codice>.
